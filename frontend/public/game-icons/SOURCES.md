# Game icons

Lost Ark and its images are trademarks and property of Smilegate RPG /
Amazon Games. This is an unofficial fan tool. The icons here are bundled with
the app (never loaded from the web) and each one is listed below with where it
came from, so any of them can be removed fast: delete the file and its line in
`frontend/lib/data/icons.ts`, and the app falls back to its generic icon.
